# Java八股学习Demo

> 专为秋招面试设计的Java核心知识点手写练习项目。
> **强调脱离AI手写代码**，每个Demo可独立运行，覆盖后端面试高频考点。

## 学习路径

按以下顺序逐模块学习，每个模块的Demo类都有 `main` 方法可直接运行：

| 序号 | 模块 | 包路径 | 面试权重 |
|------|------|--------|----------|
| 1 | Java基础 | `basic` | ⭐⭐⭐⭐⭐ |
| 2 | 集合框架 | `collection` | ⭐⭐⭐⭐⭐ |
| 3 | 多线程与并发 | `thread` | ⭐⭐⭐⭐ |
| 4 | JVM | `jvm` | ⭐⭐⭐⭐ |
| 5 | 数据库（手写SQL）| `database` | ⭐⭐⭐⭐⭐ |
| 6 | 设计模式 | `designpattern` | ⭐⭐⭐ |
| 7 | 算法与数据结构 | `algorithm` | ⭐⭐⭐⭐⭐ |

## 运行方式

```bash
# 编译
mvn compile

# 运行总入口（依次执行所有模块）
mvn exec:java

# 或在IDE中直接右键每个Demo类的main方法运行
```

## 学习建议

1. **不要复制粘贴** — 每个Demo类先看注释理解概念，然后手写一遍
2. **脱离AI** — 先尝试自己写，写不出来再看示例代码
3. **修改实验** — 在Demo基础上修改参数、增加场景来加深理解
4. **面试复述** — 学完每个模块后，尝试用语言复述核心概念

## 各模块重点

### Java基础
- 封装/继承/多态的区别和代码体现
- String为什么不可变？StringBuilder vs StringBuffer
- 异常体系：checked vs unchecked
- IO流分类和使用场景

### 集合框架
- ArrayList vs LinkedList 底层结构与时间复杂度
- HashMap put/get 流程（hash → 取模 → 链表/红黑树）
- HashSet 去重原理依赖 equals + hashCode

### 多线程
- 线程创建方式（3种）及区别
- synchronized 锁升级：偏向锁→轻量级锁→重量级锁
- 线程池7个参数的含义与拒绝策略

### JVM
- 类加载双亲委派机制
- 运行时数据区（堆/栈/方法区/程序计数器）
- GC算法：标记-清除/标记-整理/复制/分代收集

### 数据库
- 手写联表查询（INNER JOIN / LEFT JOIN）
- 索引原理（B+Tree）、最左前缀原则
- 事务ACID、隔离级别、脏读/幻读/不可重复读

### 设计模式
- 单例模式5种写法及DCL为什么用volatile
- 工厂模式与抽象工厂的区别
- 动态代理的两种实现（JDK vs CGLIB）

### 算法
- 5种排序算法手写和时间复杂度
- 二分查找及变体
- 手写链表反转
